# RAP_TRAVEL_APP

This repository is set up for the SAP RAP Travel App tutorial:

<https://developers.sap.com/tutorials/group-create-a-travel-app-with-sap-fiori-elements-based-on-odata-v4-rap-service>

## Goal

Implement the end-to-end **Travel** business object and expose it through an
**OData V4 RAP service** with a **SAP Fiori elements** UI, as described in the
tutorial.

## Scope

The implementation in this repository should follow the tutorial sequence and
cover:

- RAP data model for Travel (CDS)
- Behavior definition/implementation
- Service definition and service binding (OData V4)
- Fiori elements app generation and execution
